Featured · 2025–26 · Mobile Application

Smart Meeting Minutes Generator

An AI-powered meeting assistant that turns recorded conversations into structured minutes — automatically extracting summaries, key decisions, and action items using speech-to-text and NLP.

PythonFlaskNLP Speech-to-TextFirebase Auth FirestoreREST APIs
GitHub profile

No dedicated public repo listed yet — code is referenced from the GitHub profile above.

The why

Reviewing meeting recordings manually to capture decisions and action items is slow and easy to get wrong. This app automates that extraction so teams get structured minutes without transcribing by hand.

Technical solution

A Flask backend exposes REST APIs the Flutter mobile app calls to submit recordings and retrieve generated minutes. Speech-to-text converts audio into raw transcript text, which an NLP pipeline processes to pull out summaries, decisions, and action items. Firebase Authentication secures access, and Firestore stores meeting records for retrieval across sessions.

Notable challenge

Keeping the mobile client, Flask API, and NLP processing in sync — so a submitted recording reliably comes back as structured, readable minutes — required careful REST API design between the app and backend.
